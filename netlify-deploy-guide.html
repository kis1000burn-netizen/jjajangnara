Netlify 배포 가이드

짜장나라 세종본점 웹사이트를 Netlify에 배포하는 방법

1. Netlify 계정 만들기

1-1. Netlify 웹사이트 접속

브라우저에서 https://www.netlify.com 접속

1-2. 회원가입
  • "Sign up" 또는 "Get started for free" 버튼 클릭
  • 다음 중 하나로 가입:
    • GitHub 계정으로 가입 (권장)
    • GitLab 계정으로 가입
    • Bitbucket 계정으로 가입
    • 이메일로 가입

2. 배포 방법 선택

Netlify에는 두 가지 배포 방법이 있습니다:

방법 A: 드래그 앤 드롭 (가장 간단)

2-A-1. Netlify 대시보드 접속

https://app.netlify.com 접속 후 로그인

2-A-2. 수동 배포 시작
  • 왼쪽 상단 "Sites" 메뉴 클릭
  • "Add new site" 버튼 클릭
  • "Deploy manually" 선택
2-A-3. 파일 업로드

프로젝트 폴더 전체를 드래그 앤 드롭하거나 "Browse to upload" 클릭

업로드할 파일/폴더:

  • index.html
  • order.html
  • assets/ (폴더 전체)
  • netlify.toml
  • _redirects
2-A-4. 배포 완료
  • 파일 업로드가 완료되면 자동으로 배포가 시작됩니다
  • 배포가 완료되면 https://랜덤이름.netlify.app 형식의 URL이 생성됩니다
  • 이 URL로 웹사이트에 접속할 수 있습니다

방법 B: Git 연동 (권장 - 자동 배포)

2-B-1. GitHub에 프로젝트 업로드
  • GitHub에서 새 저장소(Repository) 생성
  • 프로젝트 파일들을 커밋하고 푸시
  • 또는 GitHub Desktop이나 Git 명령어 사용
2-B-2. Netlify에서 Git 연동
  • Netlify 대시보드 → "Add new site"
  • "Import an existing project" 선택
  • GitHub/GitLab/Bitbucket 중 선택
  • 생성한 저장소 선택
2-B-3. 빌드 설정
설정 항목 값 설명
Build command (비워두기) 정적 사이트이므로 빌드 불필요
Publish directory . 루트 디렉토리 전체
2-B-4. 배포 시작
  • "Deploy site" 버튼 클릭
  • 배포가 완료되면 URL이 생성됩니다
  • 이후 Git에 푸시할 때마다 자동으로 재배포됩니다

3. 배포 확인

3-1. 기본 확인
  • 제공된 URL로 접속하여 메인 페이지가 정상 표시되는지 확인
  • 이미지와 비디오가 정상 로드되는지 확인
  • 모바일에서도 정상 작동하는지 확인
3-2. 기능 확인
  • "주문하기" 버튼 클릭 시 order.html로 이동하는지 확인
  • 주문 페이지에서 메뉴 선택 및 장바구니 기능 확인
  • "메인으로" 버튼 클릭 시 index.html로 이동하는지 확인

4. 도메인 설정 (선택사항)

4-1. 기본 도메인

Netlify는 자동으로 your-site-name.netlify.app 형식의 도메인을 제공합니다.

4-2. 커스텀 도메인 연결
  • Netlify 대시보드 → "Site settings" → "Domain management"
  • "Add custom domain" 클릭
  • 도메인 입력 (예: www.짜장나라.com)
  • DNS 설정 안내에 따라 도메인 제공업체에서 설정

5. 사이트 설정

5-1. 사이트 이름 변경
  • "Site settings" → "Site information"
  • "Change site name" 클릭하여 원하는 이름으로 변경
5-2. 환경 변수 (필요시)
  • "Site settings" → "Build & deploy" → "Environment"
  • 필요한 환경 변수 추가

6. 주요 기능

기능 설명
무료 SSL 인증서 HTTPS 자동 적용 (보안)
CDN 전 세계 빠른 로딩 속도
자동 배포 Git 연동 시 자동 재배포
폼 처리 주문 폼 등 처리 가능 (추가 설정 필요)

7. 주의사항

  • 파일 크기 제한: 단일 파일 100MB 이하
  • 빌드 시간: 무료 플랜 300분/월
  • 대역폭: 무료 플랜 100GB/월
  • assets 폴더: 이미지와 비디오 파일이 반드시 포함되어야 함

8. 문제 해결

8-1. 배포 실패 시
  • Netlify 대시보드 → "Deploys" 탭
  • 실패한 배포의 "Deploy log" 확인
  • 에러 메시지 확인 후 수정
8-2. 파일이 보이지 않을 때
  • netlify.toml 파일의 publish 설정 확인
  • 모든 파일이 루트 디렉토리에 있는지 확인
8-3. 이미지가 안 보일 때
  • 이미지 경로가 올바른지 확인 (assets/images/...)
  • 파일명이 정확한지 확인 (대소문자 구분)
  • assets 폴더가 업로드되었는지 확인

빠른 배포 팁: 처음에는 드래그 앤 드롭 방법이 가장 빠르고 간단합니다. 나중에 자동 배포가 필요하면 Git 연동을 설정하세요.
