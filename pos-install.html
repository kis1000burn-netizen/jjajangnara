포스기 주문·관리 프로그램 설치

카운터 포스 PC에서 아래 순서로 설치하면 주문 진행판과 프린터 자동출력을 사용할 수 있습니다.

1. 주문 진행판 (웹 앱)

결제된 주문을 접수·조리·배달 단계로 관리하는 화면입니다. Edge 또는 Chrome에서 열어 앱으로 설치하세요.

주문 진행판 열기

진행판의 연결 설정에 Netlify POS_API_TOKEN을 입력한 뒤, 앱 설치 버튼으로 바탕화면·시작 화면에 설치합니다.

2. 프린터 브리지 (Windows)

신규 주문을 카운터·주방 프린터로 자동 출력하고, 매장 온라인 신호를 유지하는 관리 프로그램입니다.

프린터 브리지 다운로드
  1. ZIP을 포스 PC 고정 폴더에 압축 해제합니다.
  2. 폴더에서 install.ps1을 우클릭 → PowerShell로 실행합니다.
  3. 사이트 주소, POS_API_TOKEN, 카운터·주방 프린터 이름을 입력합니다.
  4. 설치가 끝나면 시작프로그램 등록·바탕화면 바로가기·브리지 실행이 자동으로 됩니다.

실행이 막히면 PowerShell에서
powershell.exe -ExecutionPolicy Bypass -File .\install.ps1 을 사용하세요.

3. 설치 후 확인

  1. 주문 진행판이 토큰으로 연결되고 “온라인”으로 표시되는지 확인합니다.
  2. 테스트 결제 또는 테스트 주문으로 카운터·주방 출력을 확인합니다.
  3. 브리지가 꺼지면 홈페이지가 배달 불가로 전환되므로, 포스 PC 절전을 해제해 두세요.
